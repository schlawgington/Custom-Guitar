Guitar built for EG 1004 with the purpose of increasing financial and auditory accessibility to the online guitar lesson market.

Material Cost
- Arduino Mega: $23
- 1/4in Birch Inch Wood: $4
- Copper Tape: $6
- Velostat: $12

Total Cost: $45

Making this guitar much cheaper than actual guitars.
